# Demonstration

The real Timecrate window with synthetic CLI replies. Backup counts, history and remote state are demonstration fixtures; the clip exercises the interface. Privileged commands are disabled in the disposable capture environment. No real backup, key material or cloud account is used.

- [GIF](timecrate-window.gif) · [reduced-motion still](timecrate-window-still.png)
- Source: [timecrate at `952c4232d074`](https://github.com/spencernorton/timecrate/tree/952c4232d074ec4ab588c9500f21e330c5a15daf)
- Runtime: GNOME Shell 50.1 on Ubuntu 26.04, using an isolated home and session bus.
- 11.5 seconds; 69 frames; 129,012 bytes.
- GIF SHA-256: `38d875b431744a6304f1b38c4559bbf8599bfb563430f629f18044540466e051`

Frames are captures of the real interface and are sampled at six frames per
second. The still and GIF contain only rendered pixels, without text metadata.
This is documentary footage; it does not establish a new package or hardware
qualification. Public source and normal CI remain the release evidence.
